# 🍻 ドリンク会計（簡易POS）

スマホで ± ボタンを押してドリンクの杯数を数え、合計金額を表示するだけのシンプルなPOSです。

## 機能
- ソフトドリンク（¥300）／アルコール（¥500）を ± ボタンでカウント
- 小計・合計金額・合計点数をリアルタイム表示
- リセットボタンで会計クリア（誤操作防止の確認あり）
- カウントは自動保存（リロード・画面ロックしても消えない）
- モバイル最適化（大きなタップ領域・ズーム防止・バイブ反応）

## 使い方
公開URL（GitHub Pages）をスマホで開くだけ。インストール不要。
ホーム画面に追加するとアプリのように使えます。

## カスタマイズ
価格を変えるには `index.html` 内の以下を編集してください。
```js
const PRICES = { soft: 300, alc: 500 };
```

## 技術
依存なしの単一HTMLファイル（HTML / CSS / Vanilla JS）。
